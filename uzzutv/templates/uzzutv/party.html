How to Use

In a room, the host starts the one-to-one Video Call and the guest chooses Accept or Decline. For movie fullscreen with the call still visible, use the UzzUTV fullscreen icon in the Watch Party player, not VidFast's internal iframe fullscreen button.
1
Create a party
Pick Movie or Series, enter the TMDB ID (plus season and episode for a series), then hit Create Watch Party. You'll get a 6-character room code and an invite link. The TMDB ID is the number in the title's URL on themoviedb.org. The same ID appears in the UzzUTV page URL too.
2
Invite your friends
Share the room code or the invite link. Friends paste the code into the "Join a Watch Party" box on this page to jump in as the guest, or just open the invite link. It takes them straight to the room. Each room supports one host and one guest.
3
Watch together
The host's player is the source of truth. Guests' players automatically sync to the host's position in real time. When the host pauses, plays or seeks, everyone follows along so you're all watching the same scene at the same time. Hit the 📹 Video Call button to chat face-to-face while you watch.
theaters
Watch Party
A watch party keeps everyone's playback in sync with the host in real time. The members panel, live host position and position check all work together so you never miss a scene. Pause, play and seek along with the host automatically.
videocam
Video Call
Click the 📹 Video Call button in the room to request a one-on-one call. The other person can accept or decline. Once connected, mute your mic, turn your camera on or off, minimize the call, or use Expand on desktop to turn the call into a full-page Discord-style view with the remote video filling the screen and your preview in the bottom-right. You'll need a camera and microphone, and you must allow browser access when prompted.
fullscreen
UzzUTV fullscreen
Use the fullscreen icon inside the Watch Party player. It enlarges the UzzUTV wrapper, keeping the VidFast movie and your existing call window together. VidFast's own iframe fullscreen cannot show UzzUTV overlays.
Right now each room supports one host and one guest with a one-on-one video call. Bigger rooms are planned for the future.
